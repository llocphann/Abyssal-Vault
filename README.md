# Abyssal Vault

Abyssal Vault is a reusable **Obsidian vault template** for building a structured personal knowledge and workflow system.

It ships with an organized vault structure, templates, dashboards, Bases, automation scripts, Custom Views, selected community-plugin configuration, sample content, and supporting visual assets.

## Getting started

1. Clone or download this repository.
2. Open it as an Obsidian vault.
3. Enable and trust the included community plugins as needed.
4. Review `90_System/93_Configuration/settings.md` and replace the provided placeholders with your own configuration.

Do not commit real API keys, tokens, credentials, or other private configuration when publishing a customized copy of the vault.
