# Quang hợp cơ bản

## Learning Objectives

```cornell
%%> . Mục tiêu %%
- Hiểu quang hợp là gì và sản phẩm chính.
```

## Main Notes

```cornell
%%> ? Quang hợp là gì? ;; %%
Quang hợp là quá trình thực vật dùng năng lượng ánh sáng để tạo chất hữu cơ từ CO₂ và H₂O.

- Diễn ra chủ yếu trong lục lạp.
- Tạo glucose và giải phóng O₂.
```

```cornell
%%> ! Phương trình khái quát %%
6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂
```

## Summary

```cornell
%%> * Tóm tắt %%
Quang hợp chuyển năng lượng ánh sáng thành năng lượng hóa học được lưu trong glucose.
```
